# Music

`music.m4a` is a soft music-box version of Brahms' Lullaby, generated by
`tools/make_lullaby.py`. The melody (1868) is public domain and the recording
is synthesised from scratch, so it's free to share.

It starts when guests tap the blocks; the round button bottom-right
pauses/resumes it.

Want a different song? Drop an `.mp3` or `.m4a` here (128-192 kbps,
1-3 minutes, under ~3 MB) and change `music:` in `content.js` to its name.
Use a track you have the rights to share (your own recording, or a
royalty-free track, e.g. from the YouTube Audio Library or Pixabay Music).
